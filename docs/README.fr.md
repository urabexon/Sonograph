# Sonograph 🎼
> Détection de hauteur tonale en temps réel et enregistrement dans le navigateur.

## Aperçu
Sonograph est un accordeur web avec enregistrement intégré. Il détecte en temps réel la hauteur du signal audio entrant grâce à l'algorithme YIN, et affiche un défilement continu de la hauteur dans le temps.

## Fonctionnalités (prévues)
- Détection de hauteur en temps réel (algorithme YIN)
- Visualisation défilante des 30 dernières secondes
- Enregistrement local (conservation 7 jours)
- Affichage du nom de note avec options de notation et altération
- Support de la transposition pour les instruments à vent
- Tempérament juste / égal
- Responsive mobile (PWA)

### Autres commandes

npm run test            # Lancer les tests
