# Sonograph 🎼
> Real-time pitch detection and recording in the browser.

## Overview
Sonograph is a web-based pitch tuner with built-in recording. It detects the pitch of incoming audio in real time using the YIN algorithm and displays a continuously scrolling visualization of pitch over time, like a karaoke roll.

## Features (planned)
- Real-time pitch detection (YIN algorithm)
- Continuous 30-second scrolling pitch visualization
- Save recordings to local storage (7-day retention)
- Note name display with notation/accidental options
- Transposition support for wind instruments
- Just / equal temperament
- Mobile responsive (PWA)
