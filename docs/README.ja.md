# Sonograph 🎼
> ブラウザ上で動作するリアルタイムピッチ検出 + 録音アプリ

## 概要
Sonograph は Web ブラウザで完結する楽器チューナーアプリです。YIN アルゴリズムによりリアルタイムでマイク入力のピッチ（基本周波数）を検出し、時間軸に沿ってスクロール表示します。

## 機能（予定）
- リアルタイムピッチ検出（YIN アルゴリズム）
- 過去30秒のピッチ履歴をスクロール表示
- ローカルストレージへの録音保存（7日間保持）
- 表記法・変化記号の切り替え（C/D/E ↔ ドレミ、♯ ↔ ♭）
- 移調楽器対応（B♭管、E♭管など）
- 平均律 / 純正律の切り替え
- モバイル対応（PWA）
